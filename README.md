# Shedo Student Academic Early-Warning System

A machine-learning-based Streamlit application for identifying students who may need additional academic support.

### Features

* Student CSV upload
* Academic risk prediction
* Student profiles
* Risk dashboard and visualizations
* Intervention tracking
* Parent/guardian report support
* Downloadable reports

### Technologies

Python • Streamlit • Pandas • NumPy • Scikit-learn • Joblib

### Run

```bash
pip install -r requirements.txt
streamlit run Shedo_App.py
```

### CSV Features

```text
Student_ID
Attendance_Rate
Missing_Assignments
GPA_Trend
Current_GPA
Previous_GPA
Assessment_Average
Study_Activity
```

> This project is a prototype decision-support tool. Model predictions should be reviewed by qualified school staff.
